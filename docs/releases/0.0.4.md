# Daydreaming 0.0.4

A friendlier way to ask for the next feature.

- Adds “Ask for a feature…” to the menu bar menu and uses the same name in Help and About.
- Gives the request window a colorful header, a more compact layout, and clear explanations beneath the relevant fields.
- Extends the About window's gradient into the title bar.
- Keeps the menu bar's quiet status and weather information at the bottom.

Requires macOS 26 or later.
