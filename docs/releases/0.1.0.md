# Daydreaming 0.1.0

- Choose a picture, describe your idea, and preview changes through the day.
- Crop the original inline and choose how often your desktop changes.
- Browse earlier pictures and cached variations.
- Keep daily image limits, safe cancellation and successful-update timestamps.
- Check for signed app updates and optionally share anonymous installation statistics.

This release requires macOS 26 or later and an OpenAI API key for new images.
