# Daydreaming 0.1.0

- Choose a picture, describe your idea, and preview changes through the day.
- Crop the original inline and choose how often your desktop changes.
- Browse earlier pictures and cached variations.
- Keep daily image limits, safe cancellation and successful-update timestamps.
- See the represented hour separately from when a saved picture was made and applied.
- Open your picture and idea in Codex for a manual, user-reviewed creation.
- Check for signed app updates and optionally share anonymous installation statistics.

This release requires macOS 26 or later. Automatic previews and wallpaper updates require an OpenAI API key. Create in Codex opens the separate Codex app, where you review and send the request yourself.
