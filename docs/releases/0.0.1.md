# Daydreaming 0.0.1

Our first release: your favorite picture, changing with the day.

- Choose a picture and describe how you want it to feel.
- Preview the day and crop your original in the same window.
- Let your wallpaper follow the time and local weather on your chosen schedule.
- Revisit previous pictures and reuse saved variations.
- Set a daily image limit and see update progress in the menu bar.
- Send a feature prompt to Freek from the Help menu.

Daydreaming is free and postcardware. Image creation uses your own OpenAI API account and its credit. Requires macOS 26 or later.
